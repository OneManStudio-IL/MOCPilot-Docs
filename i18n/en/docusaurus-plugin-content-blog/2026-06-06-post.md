## 🚀 MOCPilot 2026.4.0 — Undo/Redo, Hub Profiles & Builder Fixes

We’re happy to announce the release of **MOCPilot 2026.4.0**, available on **Android**, **iOS**, and **macOS**.

This update adds undo and redo history for block programs, improves hub setup in the profile builder, and fixes several block builder and device-control issues.

---

<!-- truncate -->

## ✨ What’s New in 2026.4.0?

### 🧱 Block Program History

- Added **undo and redo history control** for block programs

### 🔌 Hub Profile Builder

- Decoupled **hub addition** from the connection flow in the profile builder
- Hubs can now be added to a profile without requiring an immediate connection

### 🛠 Builder & Device Fixes

- Fixed the translated **delete-blocks** context menu label
- Fixed the **WeDo 2.0 motor port command mapping**, restoring control when using one of two motor ports
- Fixed an issue with the **front joint type** of blocks so snapping between these blocks now works correctly
