# Оновлення прошивки

MOCPilot может обновлять прошивку поддерживаемых LEGO Powered Up хабов, когда для них доступна новая совместимая версия.

Обновление прошивки может быть необходимо для корректной работы хаба с MOCPilot. Новая прошивка может улучшить совместимость, исправить поведение хаба и обеспечить работу функций, доступных для конкретной модели.

## Перед началом

Перед запуском обновления убедитесь, что у хаба и устройства с MOCPilot достаточно заряда батареи.

Во время всего процесса хаб должен оставаться включенным. Держите телефон, планшет или компьютер рядом с хабом, чтобы Bluetooth-соединение оставалось стабильным. Не закрывайте MOCPilot, не выключайте Bluetooth и не отключайте питание хаба во время загрузки прошивки.

:::warning Важливо
Прерывание обновления может оставить прошивку хаба в неполном состоянии. В этом случае хабу может потребоваться восстановление прошивки перед дальнейшим использованием.
:::

## Запуск обновления

Когда вы подключаете хаб, MOCPilot проверяет установленную на нем версию прошивки. Если приложение обнаружит, что требуется более новая версия, появится диалог обновления прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_1.png')} alt="Оновлення прошивки dialog" />

Выберите **Оновити**, чтобы сразу начать обновление прошивки.

Если вы не хотите обновлять хаб сейчас, выберите **Скасувати**. Обновление можно запустить позже из контекстного меню хаба.

## Обновление позже из меню хаба

Чтобы запустить обновление прошивки вручную:

1. Откройте **Мої Bluetooth-хаби**.
2. Найдите хаб, которому требуется обновление.
3. Откройте контекстное меню хаба.
4. Выберите **Оновити прошивку**.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_2.png')} alt="Оновити прошивку" />

## Во время обновления прошивки

После запуска обновления MOCPilot загружает прошивку в хаб и показывает прогресс.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_3.png')} alt="Оновлення прошивки progress" />

Дождитесь завершения загрузки. Во время применения новой прошивки хаб может перезапуститься или временно отключиться.

После загрузки прошивки MOCPilot снова начнет поиск хаба. Держите хаб рядом и дождитесь повторного подключения.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_4.png')} alt="Оновлення прошивки uploaded" />

## Завершение обновления

Когда обновление завершится успешно, MOCPilot покажет подтверждение.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_5.png')} alt="Оновлення прошивки finished" />

Выберите **OK**. Хаб переподключится, а на карточке хаба будет показана обновленная версия прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_6.png')} alt="Оновлення прошивки version" />

Теперь можно продолжать использовать хаб с MOCPilot.

## Если обновление не удалось

Если обновление не завершилось успешно, MOCPilot покажет сообщение об ошибке обновления прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_7.png')} alt="Оновлення прошивки failed" />

Сначала попробуйте перезапустить хаб и выполнить обновление еще раз:

1. Выключите хаб.
2. Включите хаб снова.
3. Держите хаб рядом с устройством.
4. Подключитесь к хабу в MOCPilot.
5. Запустите обновление прошивки еще раз.

Если хаб не отвечает нормально, может потребоваться восстановление прошивки. Следуйте инструкции [Відновлення прошивки хаба](/docs/Application/Hubs/RecoveryHubFirmware/).
