# MOCPilot - Зберіть. Керуйте. Контролюйте все.

**MOCPilot** — застосунок для створення власних профілів керування для LEGO® і сумісних Bluetooth-моделей з електроприводом.

Він дає збирачам одне місце для підключення хабів, керування моторами, читання датчиків, проєктування панелей керування та створення візуальних програм для моделей, механізмів, автомобілів, вантажівок, поїздів, роботів і власних MOC.

## Ідея

Більшості моторизованих моделей потрібно більше, ніж простий пульт. Автомобілю можуть знадобитися кермо, газ, світло, моніторинг батареї, послідовність коробки передач або спеціальна процедура запуску. Роботу можуть знадобитися датчики, події, умовна логіка та кілька хабів, що працюють разом.

MOCPilot створено для простору між базовим пультом і повноцінним середовищем програмування. Можна почати з керування моделлю з екранної панелі, а потім додавати логіку, датчики й автоматизацію.

## Профілі

**Профіль** — це центр керування однією моделлю.

У профілі можна вибрати хаби моделі, створити програму, що запускає модель, і спроєктувати панель керування.

## Створення логіки блоками

MOCPilot містить візуальний конструктор блоків. Ви можете створювати програми, з’єднуючи блоки замість написання коду.

Блоки можуть реагувати на події, керувати моторами, читати датчики, працювати зі змінними, використовувати введення з геймпада, оновлювати контролери панелі та координувати кілька дій.

MOCPilot повністю підтримує підключені фізичні геймпади. Блоки геймпада читають кнопки, тригери, напрямки D-pad і стіки, щоб можна було призначити реальний контролер моделі, якщо фізичне керування зручніше за сенсорний екран.

## Проєктування панелі керування

Панель керування — це екран, яким ви користуєтеся під час керування моделлю. Вона може містити керма, джойстики, слайдери, кнопки, перемикачі, педалі, монітори та інші контролери.

Контролери панелі й введення фізичного геймпада можна підключати до блоків і дій хаба, щоб інтерфейс відповідав моделі.

## Тримати складні моделі керованими

Коли модель зростає, профіль може зростати разом із нею. MOCPilot підтримує повторно використовувану логіку через **My Blocks**, налаштування хабів для конкретного профілю, кілька контролерів і програмні потоки, що поєднують ручне керування з автоматизацією.

<img src={useBaseUrl('/img/my-blocks/my-blocks-usage-example.png')} alt="Приклад використання My Blocks у MOCPilot" width="1100" />

Це допомагає зберігати великі програми читабельними. Наприклад, профіль може мати один користувацький блок для оновлення батареї, інший для калібрування керма й ще один для спеціального режиму їзди.

## Типовий процес

1. Створіть або відкрийте профіль.
2. Додайте Bluetooth-хаби й пристрої, які використовує модель.
3. Зберіть програму з блоків.
4. Спроєктуйте панель для їзди та взаємодії.
5. Натисніть **Play**.
6. Тестуйте, налаштовуйте й покращуйте профіль, доки модель не поводитиметься так, як потрібно.

<img src={useBaseUrl('/img/quick-start/connect-hub-flow.png')} alt="Процес підключення хаба в MOCPilot" width="1100" />

## Для кого MOCPilot

MOCPilot корисний збирачам, які хочуть:

- Кращий пульт для моторизованих LEGO® моделей.
- Спосіб керувати сумісними Bluetooth-хабами сторонніх виробників.
- Візуальне середовище програмування для механізмів і роботів.
- Готові профілі для підтримуваних офіційних наборів.
- Користувацькі панелі для автомобілів, вантажівок, поїздів, краулерів, кранів та інших MOC.
- Один застосунок, що поєднує хаби, мотори, датчики, геймпади й екранні контролери.

## Почати знайомство

- Скористайтеся [коротким посібником](/docs/Introducing/QuickStart/), щоб створити перший профіль.
- Перевірте [підтримувані пристрої](/docs/Introducing/SupportedDevices/) перед вибором обладнання.
- Перегляньте [документацію BlockBuilder](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing/), коли будете готові додати логіку.
- Ознайомтеся з [оновленням прошивки хаба](/docs/Application/Hubs/FirmwareUpdating/), якщо хаб потребує підтримуваної версії прошивки.
