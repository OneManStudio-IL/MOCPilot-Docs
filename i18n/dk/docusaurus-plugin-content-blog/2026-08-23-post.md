## 🚀 MOCPilot 2026.5.0 — Firmwareopdateringer, SBrick-support og konstruktørforbedringer

Vi er glade for at annoncere **MOCPilot 2026.5.0**, tilgængelig på **Android**, **iOS** og **macOS**.

Denne opdatering tilføjer firmwareopdatering og gendannelse for flere LEGO Powered Up hubs, introducerer support for SBrick og SBrick Plus, forbedrer blokbyggeren og kontrolpanelets arbejdsgang og indeholder mange brugerfladeforbedringer, nedbrudsrettelser og oversættelsesopdateringer.

## ✨ Hvad er nyt i 2026.5.0?

### 🔄 Firmwareopdatering og gendannelse af hubs

- Tilføjet firmwareopdatering for **Technic Hub**
- Tilføjet firmwareopdatering for **Technic Move Hub**
- Udvidet firmwareopdatering for flere understøttede hubs
- Tilføjet registrering af hubs forbundet i **gendannelsestilstand**

### 🔌 Hub-support og konfiguration

- Tilføjet support for **SBrick** og **SBrick Plus**
- Tilføjet konfigurationsændring for Technic Move Hub: **Porsche GT4 e-Performance**, **Batmobile™‎ Tumbler** og **Lamborghini Revuelto**
- Omarbejdet hub-forbindelsessider efter forbindelsestype
- Omarbejdet hub-monitoreringssiden

### 🧱 Opdateringer til blokbyggeren

- Tilføjet filtrering efter blokniveauer: **Beginner**, **Advanced** og **Guru**
- Blokniveauer kan konfigureres, når et profil-block program oprettes, redigeres eller køres
- Tilføjet **batterispænding**-blok for hubs, der leverer batterispændingsdata
- Tilføjet **effektimpuls**-blok for Technic Move Hub
- Rettet skalering med musehjul på blokpaletten

### 🎮 Gamepad og kontrolpanel

- Omarbejdet gamepad-siden og gamepadtestersiden
- Rettet tilstandsovergange for gamepaddets D-pad
- Tilføjet en kontekstmenuindstilling til at ændre temaet for kontrolpanelets element direkte
- Forbedret kontrolpanelets profiloverskrifter, sorteringsmenu, kortgradienter og afstand i oprettelsesformularen

### 🎨 Brugerflade, profiler og stabilitet

- Fjernet den gule palette fra forudbyggede profiler, så de nu matcher den almindelige profilsiden
- Forbedret det generelle udseende og mindre brugerfladedetaljer
- Tilføjet nedbrudsrettelser og intern kodeomorganisering
