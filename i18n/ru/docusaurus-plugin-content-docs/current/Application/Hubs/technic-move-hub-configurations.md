# Конфигурации Technic Move Hub

## Обзор

Technic Move Hub получил уникальную возможность в семействе хабов LEGO Powered Up: хаб может менять свое поведение в зависимости от текущей примененной конфигурации.

MOCPilot позволяет изменить конфигурацию Technic Move Hub, чтобы поведение хаба соответствовало официальному набору LEGO, которым вы хотите управлять.

## Поддерживаемые конфигурации

На данный момент известны следующие конфигурации Technic Move Hub:

- **Porsche GT4 e-Performance**
- **Lamborghini Revuelto**
- **Batmobile™ Tumbler**

## Изменение конфигурации из Мои Bluetooth-хабы

Конфигурацию можно изменить на странице **Мои Bluetooth-хабы**:

1. Откройте **Мои Bluetooth-хабы**.
2. Найдите Technic Move Hub.
3. Откройте контекстное меню хаба.
4. Выберите **Выбрать конфигурацию**.
5. Выберите нужную конфигурацию.
6. Подтвердите диалог перенастройки.

<img src={useBaseUrl('/img/hubs/technic-move-hub-configurations/cfg_0.png')} alt="Контекстное меню Technic Move Hub" />

<img src={useBaseUrl('/img/hubs/technic-move-hub-configurations/cfg_1.png')} alt="Подменю конфигурации Technic Move Hub" />

<img src={useBaseUrl('/img/hubs/technic-move-hub-configurations/cfg_3.png')} alt="Диалог подтверждения перенастройки Technic Move Hub" />

:::warning Важно
Изменение конфигурации хаба записывает в хаб подпрограмму и похоже на процесс обновления прошивки.

Держите хаб включенным в течение всего процесса. Телефон, планшет или компьютер должны быть заряжены и находиться рядом с хабом, чтобы Bluetooth-соединение оставалось стабильным. Не закрывайте MOCPilot, не выключайте Bluetooth и не отключайте питание хаба во время изменения конфигурации.

Прерывание изменения конфигурации может повредить прошивку хаба. В этом случае перед дальнейшим использованием может потребоваться восстановление прошивки. Если восстановление необходимо, следуйте инструкции по [восстановлению прошивки хаба](/docs/Application/Hubs/RecoveryHubFirmware/).
:::

Во время перенастройки хаб не отвечает на обычные команды. Его LED мигает ступенчатой цветовой индикацией до завершения процесса. После применения новой конфигурации хаб переинициализируется.

## Блоки конфигурации

MOCPilot также содержит блоки для чтения и изменения конфигурации Technic Move Hub во время выполнения программы.

### Установить конфигурацию хаба

<img src={useBaseUrl('/img/blocks/block_hubs_set_hub_config.svg')} alt="Блок Установить конфигурацию хаба" />

Блок **Установить конфигурацию хаба** меняет выбранный хаб на один из поддерживаемых профилей конфигурации.

- Выбор хаба: выбирает хаб для перенастройки.
- Выбор конфигурации: выбирает целевую конфигурацию.
- Доступные конфигурации для Technic Move Hub: **Porsche GT4 e-Performance**, **Lamborghini Revuelto** и **Batmobile™ Tumbler**.

См. [документацию блока Установить конфигурацию хаба](/docs/Application/BlockBuilder/Blocks/Control/#block_hubs_set_hub_config).

### Конфигурация хаба

<img src={useBaseUrl('/img/blocks/block_hubs_all_control_hub_config.svg')} alt="Блок Конфигурация хаба" />

Блок **Конфигурация хаба** сообщает текущую конфигурацию выбранного хаба.

- Выбор хаба: выбирает хаб для чтения.
- Формат вывода: **текст** возвращает название конфигурации.
- Формат вывода: **индекс** возвращает индекс конфигурации, что удобно для сравнений в условиях.

<img src={useBaseUrl('/img/hubs/technic-move-hub-configurations/cfg_5.png')} alt="Параметры формата вывода блока Конфигурация хаба" />

См. [документацию блока Конфигурация хаба](/docs/Application/BlockBuilder/Blocks/Control/#block_hubs_all_control_hub_config).

### Импульс питания

<img src={useBaseUrl('/img/blocks/block_hubs_technicmove_motors_power_pulse.svg')} alt="Блок Импульс питания" />

Блок **Импульс питания** отправляет выбранному Technic Move Hub команду импульса мощности. Этот блок работает только когда Technic Move Hub настроен как **Batmobile™ Tumbler**.

При выполнении хаб кратковременно запускает моторы с максимально доступной мощностью и скоростью, обычно примерно на 1-2 секунды.

См. [документацию блока Импульс питания](/docs/Application/BlockBuilder/Blocks/Motors/#block_hubs_technicmove_motors_power_pulse).

## Изменение конфигурации во время выполнения программы

Конфигурацию Technic Move Hub также можно менять во время выполнения программы.

Обычный подход выглядит так:

1. Считайте текущую конфигурацию хаба.
2. Сравните ее с конфигурацией, требуемой профилем.
3. Если конфигурация отличается, установите требуемую конфигурацию.
4. После перенастройки снова считайте конфигурацию.
5. Продолжайте только тогда, когда хаб сообщает ожидаемую конфигурацию.
6. Отключите хаб или остановите программу, если требуемая конфигурация не была применена.
