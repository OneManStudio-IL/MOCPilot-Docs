# Обновление прошивки

MOCPilot может обновлять прошивку поддерживаемых хабов LEGO Powered Up, когда доступна новая совместимая версия.

Обновление прошивки может быть необходимо, чтобы хаб корректно работал с MOCPilot. Новая прошивка улучшает совместимость, исправляет поведение хаба и позволяет приложению использовать функции, ожидаемые для этой модели.

## Перед началом

Перед началом обновления убедитесь, что хаб и устройство с MOCPilot имеют достаточный заряд батареи.

Держите хаб включенным в течение всего процесса. Держите телефон, планшет или компьютер рядом с хабом, чтобы Bluetooth-соединение оставалось стабильным. Не закрывайте MOCPilot, не отключайте Bluetooth и не выключайте хаб во время загрузки прошивки.

:::warning Важно
Прерывание обновления прошивки может оставить прошивку хаба в неполном состоянии. В этом случае перед дальнейшим использованием хаба может потребоваться восстановление прошивки.
:::

## Запуск обновления

При подключении хаба MOCPilot проверяет установленную версию прошивки. Если приложению требуется более новая версия, оно показывает диалог обновления прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_1.png')} alt="Обновление прошивки" />

Выберите **Обновить**, чтобы сразу начать обновление прошивки.

Если вы не хотите обновлять прошивку сейчас, выберите **Отмена**. Обновление можно запустить позже из контекстного меню хаба.

## Обновление позже из меню хаба

Чтобы запустить обновление прошивки вручную:

1. Откройте **Мои Bluetooth-хабы**.
2. Найдите хаб, которому требуется обновление.
3. Откройте контекстное меню хаба.
4. Выберите **Обновить прошивку**.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_2.png')} alt="Обновить прошивку" />

## Во время обновления прошивки

После запуска обновления MOCPilot загружает прошивку в хаб и показывает прогресс.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_3.png')} alt="Обновление прошивки" />

Дождитесь завершения загрузки. Во время применения новой прошивки хаб может перезапуститься или временно отключиться.

После загрузки прошивки MOCPilot снова ищет хаб. Держите хаб рядом и дождитесь повторного подключения.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_4.png')} alt="Обновление прошивки" />

## Завершение обновления

Когда обновление завершится успешно, MOCPilot покажет подтверждение.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_5.png')} alt="Обновление прошивки" />

Выберите **OK**. Хаб переподключится, а карточка хаба покажет обновленную версию прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_6.png')} alt="Обновление прошивки" />

Теперь можно продолжать использовать хаб с MOCPilot.

## Если обновление не удалось

Если обновление не завершилось успешно, MOCPilot покажет сообщение об ошибке обновления прошивки.

<img src={useBaseUrl('/img/hubs/firmware-updating/fu_7.png')} alt="Обновление прошивки" />

Сначала попробуйте перезапустить хаб и снова выполнить обновление:

1. Выключите хаб.
2. Снова включите хаб.
3. Держите хаб рядом с устройством.
4. Подключитесь к хабу в MOCPilot.
5. Снова запустите обновление прошивки.

Если хаб не отвечает нормально, может потребоваться восстановление прошивки. Следуйте подробной инструкции [Восстановление прошивки хаба](/docs/Application/Hubs/RecoveryHubFirmware/).
