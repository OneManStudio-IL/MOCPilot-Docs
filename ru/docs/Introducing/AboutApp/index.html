MOCPilot - Соберите. Управляйте. Контролируйте все.

MOCPilot — приложение для создания пользовательских профилей управления для LEGO® и совместимых Bluetooth-моделей с электроприводом.

Оно дает сборщикам единое место для подключения хабов, управления моторами, чтения датчиков, проектирования панелей управления и создания визуальных программ для моделей, механизмов, автомобилей, грузовиков, поездов, роботов и собственных MOC.

Что дает MOCPilot

  • Пользовательские профили для ваших собственных моделей.
  • Готовые профили для поддерживаемых официальных наборов.
  • Подключение и управление Bluetooth-хабами.
  • Визуальное программирование блоками для автоматизации и логики.
  • Контроллеры панели управления для езды и управления моделями.
  • Поддержка LEGO® Powered Up, Technic, BuWizz, SBrick, Mould King, моторов, датчиков и совместимых Bluetooth-устройств.

Идея​

Большинству моторизованных моделей нужно больше, чем простой пульт. Машине могут понадобиться рулевое управление, газ, свет, контроль батареи, последовательность переключения коробки передач или особый запуск. Роботу могут понадобиться датчики, события, условная логика и совместная работа нескольких хабов.

MOCPilot создан для пространства между простым пультом и полноценной средой программирования. Можно начать с управления моделью с экранной панели, а затем добавлять логику, датчики и автоматизацию по мере усложнения сборки.

Профили​

Профиль — это центр управления одной моделью.

В профиле можно выбрать хабы модели, создать программу, которая запускает модель, и настроить панель управления.

Готовые профили

Готовые профили — это заранее собранные примеры для поддерживаемых официальных наборов. Они полезны, когда хочется быстро начать или изучить, как устроен рабочий профиль.

Пользовательские профили

Пользовательские профили предназначены для ваших MOC и экспериментов. Вы можете создать профиль, добавить хабы, подключить моторы и датчики, собрать программу и спроектировать панель управления под конкретную модель.

Подключение хабов и устройств​

MOCPilot может подключаться к поддерживаемым Bluetooth-хабам и совместимым устройствам, а затем делать их доступными внутри профиля.

Для простой модели можно использовать профиль с одним хабом или подключить несколько хабов, если модели нужны дополнительные порты, отдельные системы питания или независимые модули.

Создание логики блоками​

MOCPilot включает визуальный конструктор блоков. Вы можете создавать программы, соединяя блоки вместо написания кода.

Блоки могут реагировать на события, управлять моторами, читать датчики, работать с переменными, использовать ввод с геймпада, обновлять контроллеры панели управления и координировать несколько действий.

MOCPilot полностью поддерживает подключенные физические геймпады. Блоки геймпада позволяют считывать кнопки, триггеры, D-pad и стики, чтобы назначить настоящий контроллер на модель, если физическое управление удобнее сенсорного экрана.

Что можно делать блочными программами
  • Запускать, останавливать и поворачивать моторы.
  • Читать уровень батареи, напряжение, наклон, ориентацию, температуру и значения датчиков.
  • Настраивать управление физическим геймпадом для руля, газа, триггеров, действий и переключения режимов.
  • Реагировать на изменения кнопок, датчиков, таймеров или контроллеров панели управления.
  • Создавать стартовые проверки перед началом движения модели.
  • Добавлять собственную логику для света, калибровки рулевого управления, режимов мощности и конфигурации хаба.
  • Использовать переменные, списки, условия, циклы, рассылки и пользовательские блоки для организации сложного поведения.

Проектирование панели управления​

Панель управления — это экран, которым вы пользуетесь во время управления моделью. Она может включать рулевые колеса, джойстики, слайдеры, кнопки, переключатели, педали, мониторы и другие контроллеры.

Контроллеры панели и ввод с физического геймпада можно связывать с блоками и действиями хаба, чтобы интерфейс соответствовал модели, а не заставлял каждую сборку использовать один и тот же пульт.

Примеры панели управления
  • Используйте руль и педали для автомобилей.
  • Используйте слайдеры для кранов, подъемников и линейных приводов.
  • Используйте кнопки для света, сигнала, переключения передач или сценарных действий.
  • Используйте мониторы для отображения батареи, скорости, значений датчиков или состояния программы.
  • Используйте подключенный геймпад, если предпочитаете физические кнопки, стики и триггеры сенсорному управлению.

Как удерживать сложные сборки под контролем​

По мере роста модели может расти и профиль. MOCPilot поддерживает переиспользуемую логику через My Blocks, настройку хабов для конкретного профиля, несколько контроллеров и программные потоки, объединяющие ручное управление с автоматизацией.

Это помогает сохранять большие программы читаемыми. Например, в профиле может быть один пользовательский блок для обновления батареи, другой для калибровки рулевого управления и еще один для специального режима езды.

Типичный рабочий процесс​

  1. Создайте или откройте профиль.
  2. Добавьте Bluetooth-хабы и устройства, которые использует модель.
  3. Соберите программу из блоков.
  4. Спроектируйте панель для езды и взаимодействия.
  5. Нажмите Play.
  6. Тестируйте, настраивайте и улучшайте профиль, пока модель не начнет вести себя так, как нужно.

Для кого MOCPilot​

MOCPilot полезен сборщикам, которым нужны:

  • Более удобный пульт для моторизованных LEGO® моделей.
  • Способ управлять совместимыми Bluetooth-хабами сторонних производителей.
  • Визуальная среда программирования для механизмов и роботов.
  • Готовые профили для поддерживаемых официальных наборов.
  • Пользовательские панели для машин, грузовиков, поездов, краулеров, кранов и других MOC.
  • Одно приложение, которое объединяет хабы, моторы, датчики, геймпады и экранные контроллеры.

Начать изучение​

  • Следуйте краткому руководству, чтобы создать первый профиль.
  • Перед выбором оборудования проверьте поддерживаемые устройства.
  • Изучите документацию BlockBuilder, когда будете готовы добавить логику.
  • Ознакомьтесь с обновлением прошивки хаба, если хабу требуется поддерживаемая версия прошивки.
