## 🚀 MOCPilot 2026.5.0 — Firmware Updates, SBrick Support & Builder Improvements

We’re happy to announce the release of **MOCPilot 2026.5.0**, available on **Android**, **iOS**, and **macOS**.

This update adds firmware update and recovery support for more LEGO Powered Up hubs, introduces SBrick and SBrick Plus support, improves the block builder and dashboard workflow, and includes many UI refinements, crash fixes, and translation updates.

<!-- truncate -->

## ✨ What’s New in 2026.5.0?

### 🔄 Hub Firmware Update & Recovery

- Added firmware update support for **Technic Hub**
- Added firmware update support for **Technic Move Hub**
- Extended firmware update support for additional supported hubs
- Added detection for hubs connected in **recovery mode**

### 🔌 Hub Support & Configuration

- Added support for **SBrick** and **SBrick Plus**
- Added Technic Move Hub configuration change: **Porsche GT4 e-Performance**, **Batmobile™‎ Tumbler** and **Lamborghini Revuelto**
- Reworked hub connection pages by connection type
- Reworked the hub monitoring page

### 🧱 Block Builder Updates

- Added block level filtering: **Beginner**, **Advanced**, and **Guru**
- Block levels can be configured while creating, editing, or running a profile block program
- Added **battery voltage** block for hubs that provide battery voltage data
- Added **power pulse** block for Technic Move Hub
- Fixed mouse wheel scale changes on the blocks palette

### 🎮 Gamepad & Dashboard

- Reworked the gamepad page and gamepad tester page
- Fixed D-pad gamepad state transitions
- Added a context menu option to change dashboard control theme inline
- Polished dashboard profile headers, sort menu, card gradients, and create form spacing

### 🎨 UI, Profiles & Stability

- Removed the yellow palette from pre-built profiles so they now match the regular profiles page
- Improved overall appearance and minor UI details
- Added crash fixes and internal code reorganization
